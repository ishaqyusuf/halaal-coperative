# Audit Current Backfill And Brought-Forward Surfaces

Type: research
Status: open
Blocked by:

## Question

Where does the current product already distinguish full historical backfill from brought-forward opening position, and where is that distinction missing or only expressed as copy?

Inspect Getting Started, member creation, member backfill baseline, finance settings, reports, onboarding readiness checks, relevant DB queries, and Brain docs. The answer should list the current surfaces and identify the gaps that the new tenant-level mode must close.

## Comments

- User clarification: the most important distinction should appear in the member backfill/member creation flow. If the cooperative is configured for brought forward, the member flow should not present a generic backfill path as the main next step.
