# Bugs

## Purpose
This directory tracks confirmed defects, regression notes, and debugging context that should remain available to future agents and maintainers.

## How To Use
- Add one markdown file per durable bug investigation or resolved defect.
- Link related tasks, PRs, tests, and affected feature docs.
- Move temporary scratch notes into a durable bug file when the finding should be remembered.
