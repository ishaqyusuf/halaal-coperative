# 10 - Add Collection Source Batch Posting

**What to build:** Finance staff can stage, review, adjust, and post monthly commitments by Collection Source with exception handling, references, and audit evidence.

**Blocked by:** 09 - Add Collection Source To Member Setup And Editing.

**Status:** completed

- [x] Staff can select a period and active Collection Source to preview eligible members.
- [x] Preview rows show expected commitment, eligible member status, and any blockers such as missing active commitment plans.
- [x] Batch rows are staged before posting and can be reviewed before contributions are created.
- [x] Staff can mark all or selected rows as collected, adjust paid amounts, and record exception reasons.
- [x] Posting selected rows creates normal contribution records and leaves skipped or exception rows staged/unpaid.
- [x] Batch creation, row exceptions, and final posting create audit evidence with period, source, totals, actor, and reference/note.
- [x] Tests cover staged-first behavior, duplicate prevention, partial payments, missing commitment plans, and tenant isolation.
