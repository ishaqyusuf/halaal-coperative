# Prototype Operation Profile Sub-step Flow

Type: prototype
Status: open
Blocked by: 01, 02

## Question

What should the improved Operation Profile experience look and feel like?

Create a low-fidelity but concrete prototype or markdown storyboard for the guided flow. It should show:

- Main title and framing, likely "Let's know about your operation" or a cleaner alternative.
- One focused sub-step per cooperative operation area.
- Bold, clean service panels with clear descriptions and fewer visible options.
- Previous/Next behavior across sub-steps.
- Review/save state.
- Motion behavior for step transitions and option selection.
- Desktop and mobile layout expectations.

The answer should link the prototype artifact and decide the recommended visual/interaction direction.

## Comments

Recommendation: prototype the flow as a clean guided setup titled "Let's know about your operation" or "Tell us how this cooperative operates." Each sub-step should focus on one decision area with bold service title, one-sentence explanation, 2-3 large selectable options, and any policy fields revealed only after the relevant choice.

Use motion sparingly: slide/fade between sub-steps, selected option elevation/background transition, and a subtle progress bar. Avoid card-heavy nesting. The UI should feel like a polished setup wizard, not a settings table.
