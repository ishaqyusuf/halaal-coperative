# Define Migration Mode Domain Semantics

Type: grilling
Status: open
Blocked by:

## Question

What exactly should the two tenant setup modes mean in Halaalvest domain language?

Resolve the names, admin-facing descriptions, required records, optional records, audit posture, and mutability rules for:

- Historical backfill
- Brought forward

The answer should make clear how each mode treats member savings, shares, charges, financing/procurement outstanding balances, businesses, profit entries, and profit-sharing seasons.

## Comments

- User clarification: the two setup modes should be named `Historical backfill` and `Brought forward`. Each mode needs a description under it explaining what the cooperative must do. Historical backfill means entering past records so history can be reconstructed. Brought forward means entering the current cooperative/member status without entering every past record, then continuing operations from that current state.
