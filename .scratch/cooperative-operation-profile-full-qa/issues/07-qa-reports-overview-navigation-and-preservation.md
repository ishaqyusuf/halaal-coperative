# QA Reports Overview Navigation And Preservation

**Type:** task
**Status:** ready-for-agent

**Blocked by:** QA Staff Service Workspaces And Server Guards

## Question

Do reports, overview queues, and role-filtered navigation hide unused disabled services while preserving visibility for existing records, pending reviews, and outstanding obligations?

## Acceptance Criteria

- Verify staff and member navigation filtering for disabled unused services and services with records.
- Verify overview action queues include pending service work only when enabled or when records need action.
- Verify report export cards hide unused disabled services and reappear when records exist.
- Verify route-title behavior and direct route access do not break when nav entries are hidden.
- Verify no existing financial history, statement evidence, report evidence, or audit evidence disappears because a service is closed to new requests.
