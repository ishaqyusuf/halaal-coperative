# 01 - Shared Mobile UI Rhythm And Primitive Audit

**What to build:** The existing mobile app has a refreshed shared visual foundation for the warm cooperative fintech direction, using existing NativeWind-first primitives rather than a second design system.

**Blocked by:** None - can start immediately.

**Status:** done

- [x] Shared section cards, stat cards, service tiles, list rows, status badges, stale/offline banners, empty states, and confirmation rows follow one consistent visual rhythm.
- [x] Repeated cards, rows, buttons, tabs, and tiles have stable dimensions that prevent label, loading, and badge layout shifts on compact phone sizes.
- [x] Semantic states for success, warning, stale/offline, blocked, neutral, and destructive UI use stable accessible colors from the existing mobile theme tokens.
- [x] Icon buttons, service tiles, tabs, and interactive rows expose accessible names without adding visible instructional copy.
- [x] The refresh does not introduce dashboard/web imports, browser-only utilities, a parallel component library, decorative gradients, or screen-local finance calculations.
