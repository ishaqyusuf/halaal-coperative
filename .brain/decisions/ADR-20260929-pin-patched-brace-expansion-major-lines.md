# ADR: Patch brace expansion within each selected major line

Date: 29 September 2026
Status: Accepted for source; clean artifact and future re-resolution checks open

## Context and decision

The lock selected `brace-expansion@1.1.13` below minimatch 3, `2.1.1` below minimatch 9, and `5.0.5` below minimatch 10. Their declared ranges are `^1.1.7`, `^2.0.2`, and `^5.0.5` respectively. The [unbounded intermediate-array advisory](https://github.com/advisories/GHSA-rgw5-rvv9-x895) names 1.1.18, 2.1.4 and 5.0.9 as patched; those versions also clear the other currently reported brace-expansion advisories. Keep the three major lines separate and select their first patched versions in the lock.

Bun 1.3.0 recorded version-scoped and parent-version-scoped override syntax in disposable probes but resolved newer copies instead of the exact requested versions. The main manifest therefore gains no misleading override. Only the 12 existing `bun.lock` brace-expansion version/integrity entries were changed, using exact entries generated by a disposable Bun probe with direct aliases for each patched version. A subsequent normal `bun install --lockfile-only` preserved the lock byte for byte; frozen install passed. Re-audit after future lock regeneration or package-manager upgrades because the manifest alone does not preserve these exact patch selections.
