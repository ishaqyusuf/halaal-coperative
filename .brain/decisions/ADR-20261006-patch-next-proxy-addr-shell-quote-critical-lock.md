# ADR: Patch new critical Next, proxy-addr and shell-quote lock findings

Date: 6 October 2026
Status: Accepted for local source; clean accepted artifacts and store release remain open

## Context

A fresh exact-lock `bun audit --audit-level=high` on primary `main` reported **3 critical/19 high** on lock SHA-256 `a384cb7e483400a5e5cc46f69a0067affd8cfa621572a7e707662c5a0bfb9c34`. [Next's ImageResponse advisory](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j) affects 16.2.0–<16.3.6; the public marketing and dashboard apps and tenant-url package selected 16.3.3. Marketing has a static `next/og` social image with no observed user-supplied SVG value, but the release lock still needs the patch. [proxy-addr's advisory](https://github.com/advisories/GHSA-jqcg-44mw-7w3h) patches at 2.0.8, within Express 5.2.1's `^2.0.7` range. [shell-quote's advisory](https://github.com/advisories/GHSA-pqg4-j6r4-53mv) patches at 1.11.0, within React Devtools Core 6.1.5's `^1.6.1` range. The installed root versions were 2.0.7 and 1.9.0 respectively.

`@react-email/ui@6.9.5` separately hard-pins Next 16.3.3 for its development preview. Even the current 6.11.0 published manifest still names 16.3.3. This nested selection kept one critical after the public app updates. The email preview is a development tool, not a public release service, but it remains part of the exact source lock.

## Decision

Pin direct web-app and tenant-url development Next dependencies to **16.3.6** and require tenant-url peers at `^16.3.6`. Add root overrides `proxy-addr:2.0.8` and `shell-quote:1.11.0`, both within their parents' declared ranges. Add a parent-scoped `@react-email/ui>next:16.3.6` override as an explicit exception to that package's exact 16.3.3 pin. Bun 1.3.9 did not reselect the nested Next copy from the scoped override alone, so ten nested Next, `@next/env` and platform SWC lock entries were replaced with the 16.3.6 metadata and integrity already generated by Bun's registry-backed root resolution. Keep the development preview off public hosting. Reinspect this selection after any lock regeneration or React Email/Bun update; do not assume the override survives re-resolution without a frozen-install and exact-lock audit.

## Verification and limits

The final lock SHA-256 is `331b898b375d45b76efacb23fb90120a46f4b485131cddd120d5913da4476544`. Relative to the verified v128 source lock, all workspace manifest changes are the intended direct Next pins and root overrides. Bun also refreshed compatible browser-data entries while resolving; the package-entry delta is 28 changed entries, including the direct and nested Next runtime/compilers, proxy-addr and shell-quote. No package was added or removed. `bun install --frozen-lockfile --ignore-scripts` passed, and the exact audit is now **0 critical/19 high**. Local Bun retained three stale ignored app/tenant Next symlinks even after a forced frozen reinstall; they were corrected to the installed root 16.3.6, and all four checked callers (including React Email UI) then resolve 16.3.6. These ignored-link repairs are local checkout state, not a substitute for clean release archive inspection.

The proxy fixture rejects an unrelated IPv4 address for a malformed mapped trust subnet and accepts only the intended address under the correct `/104` mapped prefix. The shell-quote fixture rejects a line terminator after a comment token with `TypeError`. Marketing and dashboard TypeScript and optimized local Next 16.3.6 builds pass; marketing includes `/opengraph-image` and the six public legal routes. Email TypeScript passes. The React Email CLI preview build could not finish because its generated isolated preview invokes `npm install`, which failed on a local npm cache permission error. The generated preview was removed; its copied package still pins Next 16.3.3 independently of the root lock. Do not claim a tested hosted preview or ship that generated tree. Accepted Linux/web/Trigger and signed mobile artifacts, the 19 high findings, policy publication and the owner's cloud build/deploy/OTA/submission hold remain open.

A later Sharp 0.35.5 lock refresh deduplicated the previously separate React Email UI Next lock entries into the patched root Next 16.3.6 selection. The new exact lock is `56306a168341965281a2468ab71185237baaad6ff1d2916d216a124c065d59f6`; audit remains 0 critical/19 high and both optimized web builds pass. The owner subsequently lifted the blanket cloud hold, subject to the outstanding release gates. The prior hold statement above records the state when this decision was first drafted.
