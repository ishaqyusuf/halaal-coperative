# Halaalvest Mobile UI Flow Reference Links

Purpose: lightweight visual reference index for the mobile UI refresh. These are inspiration links only. Do not copy brand marks, artwork, exact layouts, icon sets, or proprietary assets.

## Selected References

1. Musemind Finance Dashboard UI Mobile Banking App
   - Link: https://dribbble.com/shots/26805472-Finance-Dashboard-UI-Mobile-Banking-App
   - Borrow: clean finance dashboard hierarchy, top account summary rhythm, organized metric cards, recent-activity style rows, and fast scanning.
   - Avoid: blue/purple fintech palette and generic bank/card-control language.

2. Pocketbook UI Design by Jaja Studio
   - Link: https://dribbble.com/shots/14037543-Pocketbook-UI-Design-by-Jaja-Studio
   - Borrow: warmth, friendly onboarding rhythm, soft personal-finance tone, simple account summary feel.
   - Avoid: copying brand identity, motion treatment, and any consumer-budgeting copy that does not map to cooperative operations.

3. PaySense / Asset Management Fintech APP by Slick
   - Link: https://dribbble.com/shots/21464498-Asset-Management-Fintech-APP
   - Borrow: polished bottom navigation, finance card rhythm, secondary analytics surfaces, app-store-level finish.
   - Avoid: speculative investment framing, crypto/trading energy, oversized decorative screens, and heavy playful illustration.

## Halaalvest Translation

- Member app: trust-first, readiness-first, action-first.
- Admin app: exception-led, queue-first, compact and operational.
- Palette: warm ivory background, near-white surfaces, black primary actions, gold accents, green success, amber warning, red destructive.
- Shape: 8px radius for repeated cards and rows; larger radius only for auth/bottom sheets/profile readiness panels.
- Navigation: five or fewer bottom tabs per role; use More for secondary features.
- Forms: section groups, sticky submit, server-confirmed submit state, draft state, stale/offline guard, confirmation sheet.
- Guardrail: no screen-local finance logic and no generic trading/neobank tone.
