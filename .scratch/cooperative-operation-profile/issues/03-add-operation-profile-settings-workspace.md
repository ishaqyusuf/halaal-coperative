# 03 - Add Operation Profile Settings Workspace

**What to build:** Tenant admins can revisit and update service access modes after setup, with clear warnings, audit logs, and guarded changes for disabling, making read-only, or removing member self-service access.

**Blocked by:** 01 - Persist Tenant Operation Profile Defaults.

**Status:** done

- [x] Tenant admins and super admins can view the saved Operation Profile from cooperative settings.
- [x] Authorized admins can update service access modes and related operation-profile settings.
- [x] Finance policy details remain separate from broad service activation/access decisions.
- [x] Disabling, making read-only, or removing member self-service requires a reason.
- [x] Every Operation Profile change creates an audit record with before/after values.
- [x] Unauthorized roles cannot change operation-profile activation or access settings.
